# Tesla Direct Sales

Tesla vehicle and accessory sales storefront built with React and Vite.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

Build for production with `npm run build`.

## Vercel

Set the Vercel project root to `Tesla-main` and use the default Vite settings:

- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`

Set `VITE_GIVEAWAY_URL` to the deployed giveaway site URL so the giveaway links work outside local development.
